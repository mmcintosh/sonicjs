# AI Documentation Folder

This folder contains documentation generated by AI during development sessions.

## Purpose

- Session state files for context recovery
- Analysis documents from debugging/investigation
- Workflow references and guides
- Temporary notes and status updates

## Management

These files are **not tracked in git** (see `.gitignore`).

You can:
- **Review** files when needed for context
- **Delete** files after issues are resolved
- **Keep** useful references (workflow guides, major decisions)
- **Ignore** temporary session files

## Going Forward

The AI will place all documentation files here instead of cluttering the root directory.

**Tip**: Periodically clean out old files:
```bash
# Delete all files older than 30 days
find .ai-docs -type f -mtime +30 -delete

# Or just delete everything when done with a session
rm -rf .ai-docs/*
```
